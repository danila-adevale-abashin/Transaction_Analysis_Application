# Transaction Analysis Application

Приложение для анализа банковских транзакций из Excel-файлов. Генерирует JSON-данные для веб-страниц, формирует отчеты и предоставляет аналитические сервисы.

## Функциональность проекта

### 1. Веб-страницы (модуль `views.py`)
Реализована страница **«Главная»**, которая генерирует JSON-ответ для фронтенда:
*   Приветствие в зависимости от времени суток.
*   Статистика по каждой банковской карте (сумма расходов и кешбэк).
*   Топ-5 транзакций по сумме платежа.
*   Курсы валют и цены на акции (через внешние API).

### 2. Сервисы (модуль `services.py`)
*   **Инвесткопилка**: функция `investment_bank`, которая считает, сколько денег удалось бы отложить, если бы все траты округлялись до заданного лимита (10, 50 или 100 рублей). Реализовано с использованием элементов функционального программирования (`filter`, `map`).

### 3. Отчеты (модуль `reports.py`)
*   **Траты по категории**: функция `spending_by_category`, которая возвращает траты по заданной категории за последние 3 месяца (90 дней).
*   **Декоратор отчетов**: `report_decorator`, который автоматически сохраняет результат функции-отчета в файл `.csv`.

### 4. Главное меню (модуль `main.py`)
Пользовательский интерфейс для запуска всех вышеперечисленных функций в интерактивном режиме.
